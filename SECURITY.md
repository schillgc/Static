# Security Policy

## Scope

This repository is an archive of static HTML, CSS, Sass, image, and audio learning projects. It has no single application backend or repository-wide runtime.

## Safe use

- Treat external links and externally hosted media as third-party content; verify destinations and usage rights.
- Do not add credentials, private data, tracking identifiers, or personal contact details to static files.
- Review JavaScript and third-party assets before publishing them; static hosting does not make client-side code or embedded data private.
- Keep each exercise's dependencies and build steps isolated. Do not assume older examples are production-safe.
- Preserve original assets unless a specific change has been reviewed for rights and functional impact.

## Reporting

Report suspected vulnerabilities privately through GitHub's private vulnerability reporting feature when available. Do not post private information in public issues.
